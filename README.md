# StratX for ROB RUN (free build)

[![Download](https://img.shields.io/badge/Download-Free-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)

Free build following the StratX layout: homestead base cards, auto loot and a tuned aim curve.

## Homestead cards

The base raid module lists storage level, raid window state and card value without opening the map.

| Card | Shows |
| --- | --- |
| storage | tier and fill |
| raid state | open, cooldown |
| value | estimated haul |

## Auto loot

Loot crates auto-open within reach, priority list configurable, ammo boxes skippable.

## Aim

Chest default, curve smoothing 5.0, role filter on, FOV 5.

## Install

Admin loader, game, INSERT, load `farm`.

## Troubleshooting

Cards empty: base data version mismatch. Auto loot idle: priority list off.

Windows 10/11, Steam, EAC.
